# 工程质量检查：FD、时序指标与 SPM 重采样后的非有限体素

本章说明头动 FD、DVARS、tSNR、信号掩膜及重采样缺失值的检查方式，并介绍参数、输出和结果解读。指标用于定位问题；超阈值标记不会自动删帧，也不能代替解剖与模型质量审查。

参数位置对应最终版 `config/toolkit_config.m`。以下“配置第N行”均指该文件；SPM原生能力与当前接口已开放功能在各节分别说明。

这部分对应 `toolkit_config.m` 最后的“工程质量检查”。它的作用是检查：头动有多大、整段 BOLD 信号是否出现突变、重采样后是否有缺失位置，以及输出是否满足后续计算的基本要求。

**这里会生成指标、图像和检查记录，但不会自动把一个 run 判定为“科研质量合格”。** FD 超阈值也不会自动删帧、剔除被试或回归噪声。部分覆盖异常会使程序停止，这属于工程保护。

## 一、三类检查

| 检查类别    | 通俗理解                           | 主要输入                       | 主要结果                        | 是否自动改动信号                    |
| ------- | ------------------------------ | -------------------------- | --------------------------- | --------------------------- |
| 头动 FD   | 这一帧相对于上一帧，头部位置变化有多大？           | SPM 六列运动参数                 | 每帧 FD、超阈值标记、均值和最大值          | 否                           |
| 时序 QC   | 这一段影像的信号是否稳定，有没有突然跳变或持续异常？     | 未平滑的头动后 BOLD、均值图、运动参数、固定掩膜 | DVARS、平均信号、tSNR、零值比例、曲线与空间图 | 否                           |
| 重采样覆盖保护 | 移动并重采样后，哪些位置已经没有完整观测？缺失是否符合预期？ | SPM 重采样 BOLD 与均值图          | 非有限体素记录、有限值副本、全程有效信号掩膜      | 在独立副本中把允许的固定 NaN 位置填零；保留原输出 |

这三项都可以在**一名被试、一个 run** 上完成，不需要先有组水平样本。多个被试的意义在于比较分布和发现批次异常，不是让单 run 的 QC 变得可计算。

QC 是 Quality Control，即质量检查。这里的“工程”强调文件、数值和覆盖的基本一致性；完整科研 QC 还包括解剖配准、局部畸变、脑覆盖、任务设计与后续模型残差等检查。

## 二、检查在处理流程中的位置

### 1. 不是等所有预处理结束后才统一检查

虽然配置放在文件最后，实际时序 QC 位于**头动/所选畸变处理之后，功能—结构配准、标准化和最终平滑之前**。这里评估的是未做最终空间平滑的时间序列。

当前统一入口的顺序可概括为：

```text
输入与采集信息检查 → 必要的 DICOM 转换 / dummy 帧处理
→ 按所选路线运行 STC、畸变处理与头动步骤
→ 计算 FD
→ 符合条件时生成有限值副本与全程有效信号掩膜
→ qc.enabled=true 且有均值图时，执行全时序 QC
→ 按 stopAfter 决定结束，或继续结构分割、配准、标准化、平滑
```

这张图只说明 QC 的位置；TOPUP、Apply VDM、Unwarp 的具体前后关系见 [SDC.md](SDC.md)，不能由这个简图推断所有路线的算法顺序完全相同。

### 2. 哪些情况执行，哪些情况跳过？

| 情况                                                                   | FD         | 有限值副本/覆盖保护          | 时序 QC                                  |
| -------------------------------------------------------------------- | ---------- | ------------------- | -------------------------------------- |
| `cfg.execute=false`                                                  | 不计算新结果     | 不运行                 | 不运行；此时只是输入预检                           |
| 普通 `none` 路线，有均值图                                                    | 计算         | 统一入口当前不自动走此专门分支     | `qc.enabled=true` 时运行；原重采样结果须满足全体素有限要求 |
| `fsl_topup`、SPM Apply VDM、FieldMap Unwarp 或无 VDM 的 `spm_unwarp`，有均值图 | 计算         | 运行；是否产生 NaN 不影响是否检查 | 开启后对有限值副本及其有效掩膜运行                      |
| `inputStage='sdc_corrected'`，有均值图                                    | 计算         | 运行                  | 开启后对有限值副本及其有效掩膜运行                      |
| 有头动输出，但所选 SPM 分支只写 `all`、没有均值图                                       | 计算         | 跳过                  | 跳过，写出 `TIMESERIES_QC_SKIPPED.mat`      |
| `sdc.method='spm_vdm_only'`                                          | 不计算        | 不运行                 | 不运行；这一模式只准备 VDM                        |
| `inputStage='preprocessed'`                                          | 此入口不对其正式重跑 | 此入口不对其正式重跑          | 正式执行被拒绝；仅支持相应输入核查                      |

**`cfg.qc.enabled=false` 只关闭这里的全时序指标与绘图。** 它不关闭 FD，也不关闭符合上述条件的 `finalize_realign` 覆盖保护。若某条路线没有均值图，开关设为 `true` 也不能凭空计算所需指标；后续空间步骤需要均值图时，也不能把“只写 all”当作完整链的可用设置。

实现位置：[process_run.m](../matlab/+psy/process_run.m) 中的 `motion_qc`、`finalize_realign`、`timeseries_qc` 三个调用。普通用户不需要修改这些计算文件。

## 三、FD：把六列运动参数变成一条帧间头动曲线

### 1. 六列运动参数表示什么？

SPM 的 `rp_*.txt` 通常每行对应一个保留下来的 volume，每列为一个刚体运动参数：

| 列   | 内容            | 原始单位   |
| --- | ------------- | ------ |
| 1–3 | x、y、z 三个方向的平移 | mm，毫米  |
| 4–6 | 绕三个轴的旋转       | rad，弧度 |

它们是配准估计得到的位置参数。FD 使用相邻两行的变化，不直接把当前行六个数相加。因此，缓慢位置漂移与突然跳动可能表现不同。

这里使用 **Power 风格 FD**。其他软件还可能报告 Jenkinson FD、RMS displacement 等不同定义；名称都含“位移”不代表数值与阈值可以互换。FD 的方法来源及运动对连接分析的影响见 [Power 等的原始研究](https://pubmed.ncbi.nlm.nih.gov/22019881/)。

### 2. 计算公式

令第 t 帧的平移为 d，旋转为 θ，相邻差分为：

$$
\Delta d_{i,t}=d_{i,t}-d_{i,t-1},\qquad
\Delta\theta_{i,t}=\theta_{i,t}-\theta_{i,t-1}
$$

本工具包计算：

$$
FD_t=\sum_{i=1}^{3}|\Delta d_{i,t}|
+r\sum_{i=1}^{3}|\Delta\theta_{i,t}|
$$

r 是用于换算旋转的头半径，单位为 mm。小角度旋转的弧长近似为 rθ，所以把弧度乘以毫米半径后，可与平移一起按毫米表示。

这是六项绝对变化之和，**不是三维欧氏距离，也不是每个脑区的精确真实位移**。它不能完整反映一帧内部的快速运动、所有生理噪声或未被配准准确估计的运动。

例如相邻帧平移变化为 `[0.1 -0.2 0.1]` mm，旋转变化为 `[0.002 -0.001 0]` rad，取 r=50 mm：

$$
FD=0.1+0.2+0.1+50(0.002+0.001)=0.55\ \mathrm{mm}
$$

如果阈值为 0.5 mm，该帧会被标记；影像帧仍保留。

### 3. 代码中两行参数怎样选择？

```matlab
cfg.fdRadiusMm = 50; % ：旋转换算半径，mm。 % 配置第367行
cfg.fdFlagMm = 0.5;  % ：FD标记阈值，mm。 % 配置第369行
```

| 配置               | 可填写什么                              | 含义与建议                                                    |
| ---------------- | ---------------------------------- | -------------------------------------------------------- |
| `cfg.fdRadiusMm`（配置第367行） | 有限正数，默认 `50`                       | 是换算假定，不是程序自动测得的被试头半径。成人研究可先保持默认；特殊人群若调整，应事先确定依据并在整批中一致记录 |
| `cfg.fdFlagMm`（配置第369行）   | 有限正数，默认 `0.5`；例如 `0.2`、`0.3`、`0.5` | 数字越小，标记越严格。这里只提供标记阈值，不提供普适的自动剔除标准；应结合任务、TR、样本和后续模型制定方案   |

当前判定是严格的 `FD > threshold`。例如阈值 0.5 时，FD 恰好为 0.5 不标记。

第一帧没有上一帧，本工具包把它的 FD **定义为 0**。这个 0 不证明第一帧没有运动。平均 FD 和超阈值比例均以全部 N 帧为分母，包括这个约定的首帧。

每个 run 单独计算差分，不把上一个 run 的末帧与下一个 run 的首帧相减。若已删除 D 个 dummy volumes，QC 第 k 行对应原序列第 k+D 帧；FD 首帧从保留序列重新开始，不借用已删除帧计算。

实现见 [motion_qc.m](../matlab/+psy/motion_qc.m)。时序 QC 中也按同一公式计算 FD，用于把头动和信号变化画在一起。

### 4. FD 会输出什么？

在每个 run 的输出目录中：

| 文件/字段                            | 内容                  | 怎样读                     |
| -------------------------------- | ------------------- | ----------------------- |
| `motion.tsv`：`volume`            | 保留序列中的帧号，从 1 开始     | 与该 run 的 BOLD、运动参数行一一对应 |
| `motion.tsv`：`FD_mm`             | 每帧 FD               | 看尖峰、持续升高和时间分布           |
| `motion.tsv`：`flagged`           | 是否超过阈值，0/1          | 只是标记，不代表已删帧             |
| `motion_summary.json`：`nVolumes` | 帧数 N                | 核对是否与 dummy 后帧数一致       |
| `meanFDmm` / `maxFDmm`           | 全 run 平均 FD / 最大 FD | 平均值概括整体，最大值提示最严重的单次变化   |
| `flagThresholdMm`                | 本次标记阈值              | 比较不同结果前先确认相同            |
| `fractionFlagged`                | 超阈值帧数 / N           | 0.1 表示 10%，不是 0.1%      |

低平均 FD 可能同时伴有少数很大的尖峰；最大 FD 较小也不能证明没有缓慢漂移或信号伪影。应同时看六列运动参数、FD 曲线和影像。

## 四、时序 QC 先决定“在哪些体素里计算”

### 1. 为什么需要固定掩膜？

如果把整幅矩形图像都放进 DVARS、平均信号或 tSNR 汇总，大片空气和零背景会影响结果。这里先选一组有信号的位置，再对整个 run 使用**同一组位置**。

掩膜可以理解为一个三维的 0/1 选择表：1 表示参与计算，0 表示不参与。固定掩膜避免每帧换一批体素，使曲线变化既反映信号，又反映参与计算区域变化。

### 2. 默认信号掩膜怎样生成？

设 SPM 均值 EPI 为 m(v)。程序取其所有正值，排序后选第 `ceil(0.95 × 正值体素数)` 个数作为参考值 a，再保留：

$$
M_{\mathrm{signal}}(v)=\mathbf 1\{m(v)>f\,a\}
$$

这近似是“平均 EPI 正值第 95 百分位的某个比例以上”；程序使用上述排序位置，没有调用带插值的百分位估计。f 由下面这行控制：

```matlab
cfg.qc.maskFraction = 0.2; % ：信号阈值比例。 % 配置第373行
```

若 a=5000，默认阈值就是 1000，均值信号严格大于 1000 的体素进入候选掩膜。**0.2 不是“选取最亮的20%体素”，也不是灰质概率0.2。**

| 选择               | 一般影响                | 使用建议                 |
| ---------------- | ------------------- | -------------------- |
| 比 0.2 小，例如 `0.1` | 阈值更低，可能纳入更多低信号与脑外区域 | 先看掩膜，不能仅为了体素数更多而降低   |
| 默认 `0.2`         | 当前工程默认              | 可作为初步检查起点，仍需看覆盖图     |
| 比 0.2 大，例如 `0.3` | 阈值更高，可能排除弱信号脑区      | 排除后指标变好，也可能只是删掉了困难区域 |

实际函数要求 **`0 < maskFraction < 1`**，不接受 0 或 1 作为关闭/全选开关。这里按有限数值填写；配置中的“0~1”注释应按此严格范围理解。

**它是强度信号掩膜，不是解剖全脑掩膜。** 亮的颈部、头皮或脑外组织可能进入；额眶和颞底等低信号位置也可能被排除。不能仅因文件叫 `qc_mask.nii`，就把它用于组织混杂、ROI、GLM 或连接分析。

### 3. 畸变/头动处理后还要取全程有效区域

对进入有限值处理分支的 run，程序将上述候选信号区域与“所有帧都有有限值的位置”相交：

$$
M_{\mathrm{valid}}(v)=M_{\mathrm{signal}}(v)
\land\bigwedge_{t=1}^{N}\operatorname{isfinite}(Y_t(v))
$$

随后用这个固定有效掩膜做时序 QC，不把填零的缺失位置当成正常观测。

这一交集仍然不是经过解剖审查的脑掩膜；它只进一步排除了已识别的缺失位置。

### 4. 能不能指定自己的掩膜？

底层 [timeseries_qc.m](../matlab/+psy/timeseries_qc.m) 支持 `maskFile=...`，要求是**有限值的三维图像，并且与均值 EPI 的维度和 affine 网格一致**；大于 0 的位置进入掩膜。程序不会偷偷重采样它。

当前 `toolkit_config.m` 没有通用的 `cfg.qc.maskFile` 选择项：普通分支用自动掩膜；有限值处理分支自动传入 `valid_mask.nii`。若要用额外的解剖掩膜，需要准备同网格掩膜并单独调用底层 QC，不能凭空添加一个未被读取的配置字段。

## 五、DVARS：相邻帧的信号跳变有多大？

### 1. 定义与计算

令固定掩膜内有 V 个体素，Y(v,t) 为第 t 帧的信号。当前实现为：

$$
DVARS_t=\sqrt{\frac{1}{V}\sum_{v\in M}
\left[Y(v,t)-Y(v,t-1)\right]^2},\qquad t\ge 2
$$

先对每个体素算相邻帧差值，再平方、在空间求平均，最后开平方。因此，正负变化不会简单相互抵消。

举例：两个体素相邻帧差值分别是 +3 和 −4：

$$
DVARS=\sqrt{(3^2+(-4)^2)/2}=\sqrt{12.5}\approx3.54
$$

但这两项变化的普通平均只有 −0.5。DVARS 与平均信号曲线因此回答不同问题。DVARS 与 FD 联合检查的原始背景见 [Power 等的研究](https://pubmed.ncbi.nlm.nih.gov/22019881/)；这里的具体单位和未标准化行为以工具包实现为准。

### 2. 单位与首帧约定

本工具包输出 `DVARS_native`，保留 BOLD 的原信号强度单位，**没有转换为百分比、标准化 DVARS 或 z 分数**。整幅影像乘以常数 c 后，DVARS 会乘以 |c|；所以不同软件、强度缩放和处理阶段的数字不能直接套用同一阈值。

第一帧没有前一帧，DVARS 记为 **NaN，表示未定义**。这是指标表中的合法占位，不是 BOLD 图像有坏体素。`meanDVARS` 和 `maxDVARS` 只统计第 2 至 N 帧，不把第一帧算进去。

当前没有 `cfg.qc.dvarsThreshold` 参数，也不自动标记 DVARS 异常帧。应先看同一 run 的变化形状，再结合同一协议、同一掩膜和同一处理阶段的分布讨论阈值。

### 3. 与 FD 合起来怎样看？

| 曲线表现            | 可以考虑的解释                    | 接下来检查什么                 |
| --------------- | -------------------------- | ----------------------- |
| FD 与 DVARS 同时尖峰 | 头动可能伴随信号变化                 | 看运动参数、对应影像及附近数帧，确认伪影范围  |
| FD 小而 DVARS 大   | 可能有生理变化、扫描异常、运动估计遗漏或任务相关变化 | 看原/处理后影像、事件时间、平均信号和扫描记录 |
| FD 大但 DVARS 不突出 | 区域、掩膜或信号响应未形成明显全局差分峰值      | 仍检查影像，不能因此宣布运动已无影响      |
| 两者整体平稳          | 暂未见明显帧间尖峰                  | 继续检查漂移、覆盖、局部伪影和空间配准     |

这些是排查线索，不是仅凭两条曲线就能确定的原因诊断。

## 六、tSNR：一个体素的平均信号与时间波动之比

### 1. 当前采用哪个定义？

对每个掩膜内体素，先计算时间均值与样本标准差：

$$
\mu_v=\frac{1}{N}\sum_{t=1}^{N}Y(v,t),\qquad
s_v=\sqrt{\frac{1}{N-1}\sum_{t=1}^{N}[Y(v,t)-\mu_v]^2}
$$

$$
tSNR_v=\frac{\mu_v}{s_v}
$$

tSNR 没有强度单位。这里用 N−1 的**样本标准差**，不是 N 的总体标准差；程序逐帧累计均值与平方差，避免把整个 4D 数据一次性放进内存。

例如同一体素三帧值为 `[10 11 12]`，均值 11，样本标准差 1，所以 tSNR=11。这个例子也是现有测试中的已知值。

SNR、tSNR 与任务效应相对于噪声的 CNR 是不同概念，不能把 tSNR 直接当作任务激活检测能力；定义的讨论见 [Welvaert 与 Rosseel 的方法研究](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0077089)。

### 2. 这里没有先去趋势、滤波或回归

分母包含当前时间序列的一切变化：任务诱发信号、低频漂移、头动残留、生理变化和其他噪声。因此：

- 任务反应较强，也可能增加时间标准差；不能简单解释为数据质量变差。
- 平滑、滤波、回归、序列长度和掩膜选择都会改变结果。比较处理方法时，应保持其他条件一致。
- 去均值或回归后的残差均值可能接近零，不应直接拿这里的原始均值/标准差定义评价残差质量。
- 本工具包没有“tSNR超过某数就合格”的统一阈值。

### 3. 零方差与掩膜外怎样保存？

若某体素时间标准差为 0，分母不能用于正常计算，程序把该体素 tSNR 记为 **NaN**，并计入 `zeroTemporalSDVoxels`。不是把无穷大当成“极高质量”。

`tsnr.nii` 的掩膜外为 0，掩膜内零方差位置为 NaN，其余位置为计算值。`medianTSNR` 只对掩膜内标准差大于 0 的体素取中位数；不是全矩形图像的中位数，也不是整个人脑的自动评分。

如果完全没有标准差大于 0 的体素，中位数本身没有可解释值，需要检查常量影像或掩膜。当前代码没有因此额外建立一个自动科研合格/不合格标签。JSON 中不可表示的数值可能显示为 `null`，须结合 NIfTI、MAT 与计数字段判断。

## 七、平均信号、零值比例和其他时序检查

### 1. 平均信号 `global_mean`

$$
g_t=\frac{1}{V}\sum_{v\in M}Y(v,t)
$$

这里的 global 是“当前固定 QC 掩膜内的平均”，不保证是解剖全脑均值。它保留原信号单位，用于看突然的整体下降、上升或缓慢漂移。

画出这条曲线**不等于做了 Global Signal Regression**；程序没有把它从 BOLD 中减去，也没有自动把它加入 GLM。

### 2. 零值比例 `mask_zero_fraction`

$$
z_t=\frac{\#\{v\in M:Y(v,t)=0\}}{V}
$$

这里统计掩膜内**恰好等于 0** 的比例，不是接近零的比例，也不是所有 NaN/缺失的比例。`maxMaskZeroFraction` 是这条曲线的最大值。

例如 0.02 表示该帧掩膜内有 2% 体素为零。突然升高可能需要排查覆盖或重采样问题；始终为零也不能证明没有低信号、畸变或已经被掩膜排除的坏区域。

### 3. 程序还检查哪些基本条件？

[timeseries_qc.m](../matlab/+psy/timeseries_qc.m) 逐帧读取全部保留帧，并检查：至少两帧；均值图为有限值单幅图像；每帧维度与 affine 网格和均值图一致；运动参数为对应 N×6 的有限矩阵；掩膜非空；**每帧所有体素均为有限数**。

最后一条比“只在掩膜内有限”更严格。直接把含 NaN 的原 SPM 重采样序列交给此函数，即使 NaN 全在掩膜外，也会报错。统一入口的有限值分支先准备副本，正是为了明确处理这个问题。

当前空间网格比较采用代码中的数值容差；维度相同不代表 affine 一定相同。这里不是自动修复错网格，也不是自动估计新的配准关系。

## 八、SPM 重采样后的非有限体素到底是什么？

### 1. NaN、Inf 与 0 不同

| 值              | 含义                       | 本模块怎样看待                |
| -------------- | ------------------------ | ---------------------- |
| 普通有限数，包括 0     | 可以进行普通数值计算               | 0 仍须结合背景、缺失编码和掩膜解释     |
| `NaN`          | Not a Number，可用来表示未定义或缺失 | 仅在满足固定缺失模式等条件时允许在副本中置零 |
| `Inf` / `-Inf` | 正/负无穷大                   | 拒绝，不当作共同视野缺失处理         |

`isfinite` 对 NaN 和 Inf 都返回 false，所以统称“非有限”。

### 2. 为什么头动校正反而可能产生 NaN？

头动后，一些边缘位置在部分帧需要从原图像视野之外采样，而视野外没有真实观测。SPM 的共同视野 Masking 会找出这类位置，并在整个序列中统一标为缺失。支持 NaN 的浮点格式可能保存 NaN；其他格式可能以 0 表示。该规则见 [SPM FieldMap/重采样的 Masking 说明](https://www.fil.ion.ucl.ac.uk/spm/docs/manual/FieldMap/fieldmap/#masking) 和 [SPM12 的 spm_reslice 源码](https://github.com/spm/spm12/blob/main/spm_reslice.m)。

对应相关配置为：

```matlab
cfg.realign.mask = true; % 配置第157行
```

`true` 表示启用共同视野处理，`false` 不启用该选项。关闭它可能改变边缘时间序列的可比性，并不恢复视野外信号，也不保证没有其他 NaN。普通头动、Apply VDM、Unwarp 在当前接口均把这个选项传给相应的 SPM 重采样步骤。

这与分割的组织掩膜、QC 信号掩膜、最终 Smooth 的 Implicit Masking 以及 GLM 分析掩膜是不同环节，不能互相替代。

若缺失已按整数格式存为0，有限性检查无法仅凭数值区分“有效零”和“缺失零”。当前有效区交集主要排除NaN，不会自动恢复被零编码丢失的来源信息；仍要检查零值、覆盖及上游记录。因此“没有NaN”也不代表没有缺失。

### 3. `maxResliceNonfiniteFraction=0.1` 控制什么？

```matlab
cfg.qc.maxResliceNonfiniteFraction = 0.1; % 。 % 配置第375行
```

程序逐帧计算：

$$
p_t=\frac{\text{该帧 NaN 体素数}}{\text{该帧全部三维网格体素数}}
$$

若任一帧 `p_t > 0.1`，停止该 run 并报告覆盖异常。默认 0.1 表示**整个矩形视野的 10%**，不是“允许损失 10% 的脑”，也不是“允许 10% 的帧坏掉”。等于阈值不会因这项比较而停止。

例如网格有 1,000,000 个体素，其中 30,000 个 NaN，则为 3%；若有 120,000 个，则为 12%，超过默认上限。此例只演示分母，不代表合理缺失量的通用建议。

实际函数要求 **`0 < maxResliceNonfiniteFraction < 1`**。可填有限的小数，例如 0.05 或 0.1；越小越严格。当前接口没有以 0 表示“零容忍”的选择，也不接受 1 表示完全放行。

这个阈值是工程停止线，不是经过统计推导的脑覆盖合格标准。大片空气会影响分母；少量缺失也可能正好落在关键 ROI。应同时看空间位置、`maxNonfiniteWithinSignal` 及实际研究区域，不能为了让作业跑完而盲目调高。

### 4. 只有同时满足这些条件，才生成有限值副本

[finalize_realign.m](../matlab/+psy/finalize_realign.m) 检查：

1. 至少两帧，BOLD 与单幅均值图具有一致的维度和 affine 网格。
2. 均值图全部有限，且含正信号。
3. 所有 BOLD 帧都没有 Inf。
4. 所有帧的 NaN **位置完全相同**，不只是数量相同。
5. 每帧 NaN 比例不超过设定上限。
6. 信号候选区与全程有限区相交后，至少保留 100 个体素；此最小值目前固定在实现中，未在配置开放。

满足后，另写 `realigned_finite.nii`，只将这些 NaN 位置填成 0，同时保存 `valid_mask.nii`。**原 SPM 的重采样影像保留，不直接覆盖。** 统一入口后续空间步骤使用该有限值副本。

若原输出本来就没有 NaN，这条分支仍检查并写副本。若某帧 NaN 位置变化、含 Inf 或覆盖超限，则拒绝继续；不能把任意坏值一律当作正常边缘缺失。

固定 NaN 模式与可接受比例是工程判据，**不能单独证明 NaN 必定只由 SPM Masking 引起**。输入头文件预检也不等于扫描过原始 4D 的每个数值；若怀疑输入已损坏，仍须核查原输入和处理日志。

### 5. “填零”不等于修复信号

这些位置没有被估计出真实 BOLD，也没有做插值补全或时间去噪。有效掩膜让当前时序指标排除它们，但不会自动成为所有后续 GLM/FC/ROI 的通用缺失掩膜；后续空间插值和平滑也可能影响边缘，应在对应空间重新检查覆盖。

特别要分清两种“缺失”：共同视野 NaN 是存储/采样无效位置；磁敏感信号掉落常表现为**有限但很低的值**。后者可能完全通过有限值检查，仍然是需要审查的问题。

```matlab
cfg.fdRadiusMm = 50;                          % 。 % 配置第367行
cfg.fdFlagMm = 0.5;                           % 。 % 配置第369行
cfg.qc.enabled = true;                        % 。 % 配置第371行

```

| 字段                                   | 单位/可选值           | 当前默认 | 改变后的实际作用                             |
| ------------------------------------ | ---------------- | ---- | ------------------------------------ |
| `cfg.fdRadiusMm`（配置第367行）                     | 有限正数，mm          | 50   | 改变旋转对 FD 的贡献；不改变 SPM 的运动估计和影像        |
| `cfg.fdFlagMm`（配置第369行）                       | 有限正数，mm          | 0.5  | 改变 FD 标记与超阈值比例；不自动删帧                 |
| `cfg.qc.enabled`（配置第371行）                     | `true` / `false` | true | 开启/关闭全时序计算和绘图；不关闭 FD、适用分支的覆盖保护       |
| `cfg.qc.maskFraction`（配置第373行）                | 有限数，严格在 0 与 1 之间 | 0.2  | 改变自动信号候选区域；在有效副本分支也影响最终有效信号掩膜        |
| `cfg.qc.maxResliceNonfiniteFraction`（配置第375行） | 有限数，严格在 0 与 1 之间 | 0.1  | 改变适用分支的 NaN 覆盖停止线；不是全流程所有非有限值检查的统一上限 |

建议先保留默认进行试运行，重点看掩膜与曲线。需要调整时依据研究方案和具体异常，而不是只追求更高 tSNR、更小 DVARS 或零标记帧。参数应在处理前确定，并在批次间保持可追溯。

其他相关字段：`cfg.outputRoot`（配置第17行）、`cfg.execute`（配置第23行）、`cfg.stopAfter`（配置第25行）、`cfg.continueOnError`（配置第27行）、`cfg.resume`（配置第29行），以及`cfg.realign.mask`（配置第157行）。HCP 入口的部分值由 [preprocess_config.m](../config/preprocess_config.m) 覆盖，不能只改通用文件却忽略示例预设。

### 1. 路径结构

每个被试、session 和 run 独立保存，典型布局如下：

```text
outputRoot/

      rest_run1/
```

### 3. 时序汇总 `timeseries_qc/summary.json`

| 字段                               | 含义与解读                                           |
| -------------------------------- | ----------------------------------------------- |
| `nVolumes`                       | 实际检查帧数；应与保留序列一致                                 |
| `maskVoxels`                     | 固定 QC 掩膜体素数；数量大不代表覆盖准确                          |
| `maskMethod`                     | 自动阈值或显式传入掩膜；统一入口传入自动生成的有效掩膜时也会写显式掩膜             |

| `allFrameAllVoxelFinite`         | 传入 QC 的序列全部帧/全部体素有限；若用副本，不是在声称原 SPM 输出全都有限      |

| `zeroTemporalSDVoxels`           | 掩膜内时间标准差为零的体素数；这些位置的 tSNR 不参与正常汇总               |
| `maxMaskZeroFraction`            | 任一帧掩膜内零值比例的最大值                                  |
| `definitions` / `interpretation` | 指标定义及“只作工程 QC、不自动删帧”等解释                         |

### 4. 覆盖汇总 `finite_realign/summary.json`

| 字段                                    | 含义与单位                                 |
| ------------------------------------- | ------------------------------------- |
| `status`                              | 记录固定缺失置零副本与有效掩膜的处理状态；不是科研质量评分         |
| `source` / `cleanSeries` / `maskFile` | 原重采样序列、有限值副本与有效掩膜路径                   |
| `nVolumes`                            | 被检查和写出副本的帧数                           |
| `signalMaskVoxels`                    | 仅按均值强度阈值选出的候选体素数                      |
| `validSignalVoxels`                   | 再与全程有限区相交后的体素数                        |
| `unionNonfiniteVoxels`                | 所有帧缺失位置的空间并集体素数；固定模式通过时等于每帧缺失数，不是乘以帧数 |
| `maxNonfiniteFraction`                | 实际观测到的最大单帧缺失比例；不要与配置上限混淆              |
| `maxNonfiniteWithinSignal`            | 任一帧候选信号区内缺失的最大**体素数**，不是比例            |

`finalize_realign.mat` 的 `result` 还保存 `perFrameNonfinite` 与 `perFrameWithinSignal` 两个逐帧计数数组。JSON 为避免冗长，未保存这两个数组。

### 5. 图与完成标记

`timeseries_qc.png` 从上到下是 FD、DVARS、掩膜平均信号，横轴为保留序列帧号。`mask_tsnr_qc.png` 上排显示均值 EPI 与掩膜轮廓，下排显示 tSNR；它只展示四个代表性原生体素切片，不是全部切片审查，也不是标准空间的解剖左右标签。

图像为了显示使用正强度/正 tSNR 的百分位上限；色条饱和不等于文件中的数值被裁掉，异常位置应回看 NIfTI。自动信号掩膜可能有颈部或脑外区域，应检查而非只看统计值。

`qc_provenance.mat` 保存本次输入路径、选项及汇总；`QC_COMPLETE.mat` 表示该时序 QC 函数完成。`COMPLETE.mat` 表示所选 run 流程完成，**不保证每一种可选 QC 都执行过**，更不表示人工审查完成。文件夹存在也不足以证明成功，应看完成标记和批次状态。

`motion_qc.png`、`mean_epi_qc.png` 是旧 [verify_realign.m](../matlab/+psy/verify_realign.m) 辅助检查生成的文件，不是当前统一入口必然生成的文件。`native_coreg_qc.png`、`mni_qc.png`、`spatial_checks.json` 则由另一个空间审查辅助函数生成，也不应与自动时序 QC 混为一项。

## 十一、实际怎样运行与查看？

### 1. 新数据：通常随预处理自动执行

在你的正式配置和清单中填妥输入路径、处理方法及上述五行参数，先以 `cfg.execute=false` 运行 [run_toolkit.m](../run_toolkit.m) 做预检。输入检查没有代替真正的 QC。

确认后设 `cfg.execute=true`，再次运行相同入口。若只希望跑到头动与 QC，选 `cfg.stopAfter='realign'`；`segment` 或 `smooth` 也会先执行适用的 QC，再继续相应步骤。

先查看 `batch_status.tsv` 是否有失败，再按 run 打开时序汇总、两张图与覆盖汇总。批量支持来自清单多行，每个被试的每个 run 单独一行；24 名被试各两个 run 是 48 行，不是 24 行。

修改参数后，使用新的 `cfg.outputRoot`。当前恢复只复用输入、配置、代码及必需输出相同的已完成 run，不覆盖半成品，也不会把改变 QC 参数视作可直接覆盖旧结果的例外。

### 2. 只读取已有结果，不重新处理

可以在 MATLAB 中读取一个已有 run 的汇总：

```matlab
runDir = 'E:/MyStudy/derivatives/preproc_v1/sub-S01/rest_run1'; % 换成实际run目录。
motion = jsondecode(fileread(fullfile(runDir,'motion_summary.json')));
signal = jsondecode(fileread(fullfile(runDir,'timeseries_qc','summary.json')));
disp(motion)
disp(signal)
frames = readtable(fullfile(runDir,'timeseries_qc','timeseries.tsv'), ...
    'FileType','text','Delimiter','\t');
flaggedVolumes = frames.volume(frames.FD_flag == 1); % 只是列出帧号。
```

这段只读结果，不删帧、不重做预处理；如果关闭或跳过了时序 QC，相应文件不存在，应先确认原因。

### 3. 已有旧版 realign 结果：独立批量 QC

独立入口为 [run_timeseries_qc.m](../run_timeseries_qc.m)，它读取 [config/qc_config.m](../config/qc_config.m)：

| `qc_config.m` 行号 | 字段               | 怎样填                                                               |
| ---------------- | ---------------- | ----------------------------------------------------------------- |
| 4                | `cfg.spmPath`（配置第15行）    | SPM 安装目录，自动寻找失败时填写绝对路径                                            |
| 5                | `cfg.inputRoot`  | 已有 run 结果的批次根目录，包含 `input_info.mat`、一个 `mean*.nii` 和一个 `rp_*.txt` |
| 6                | `cfg.outputRoot`（配置第17行） | 全新的独立 QC 输出根目录，不能等于或位于 inputRoot 内，也应放在精简发布目录之外                   |

FD 半径、阈值和信号掩膜比例沿用各 run 的 `input_info.mat`，不是重新读取当前 `toolkit_config.m`。独立入口没有 `execute` 开关，运行即开始 QC；只读已有影像，在新的 QC 目录写结果。

**这个批量入口主要适配旧普通 Realign 的命名布局，并不是所有统一入口输出的通用复查器。** 当前 [qc_batch.m](../matlab/+psy/qc_batch.m) 从均值名推导 `r<输入名>.nii`：不自动选择 `finite_realign/realigned_finite.nii`，不自动带入其有效掩膜，也不理解全部自定义 Unwarp/Apply VDM 前缀。因此，含 NaN 的原输出或不匹配的命名会失败；不能因为文件来自本工具包就保证可直接重跑。

它逐 run 记录 `qc_batch_status.tsv`，失败后继续其他 run，最后入口会提示有失败。它不重新执行头动、标准化或平滑，也不会自动修复失败输入。

### 4. 明确路径后，直接调用底层时序 QC

需要自定义输入时，可以使用以下形式；示例路径全部替换，并先确保输入确实满足函数要求：

```matlab
toolkitRoot = 'D:/CogNeuro_fMRI_Toolkit';
addpath(fullfile(toolkitRoot,'matlab'));
addpath('D:/matlab/atoolbox/spm12'); % 换成实际SPM安装位置。

series = 'E:/MyStudy/working/realigned_finite.nii'; % 全帧有限的未平滑BOLD。
meanFile = 'E:/MyStudy/working/mean_epi.nii';       % 与BOLD相同网格的有限3D均值图。
motionFile = 'E:/MyStudy/working/rp_epi.txt';      % 与保留帧对应的N×6参数。
maskFile = 'E:/MyStudy/working/qc_mask_aligned.nii';% 有限、非空、同网格的3D掩膜。
out = 'E:/MyStudy/qc_review_v2/sub-S01/rest_run1';  % 必须尚不存在。

summary = psy.timeseries_qc(series,meanFile,motionFile,out, ...
    maskFile=maskFile,fdRadiusMm=50,fdFlagMm=0.5);
```

若不用自定义掩膜，可删去 `maskFile=maskFile` 并传 `maskFraction=0.2`，由均值图生成自动掩膜。这种直接调用没有自动补跑有限值处理；不能把任意含 NaN 输入交给它。

还要留意：完整链中的 Coregister: Estimate 会更新均值 EPI 和所用 BOLD 的空间头信息；较早生成的 QC 掩膜未必同步更新。原先保存的时序 QC 仍描述当时的计算，但若事后重新组合这些文件运行新 QC，必须重新核对网格。不要为通过检查而直接改写已有成功影像或假定尺寸相同就足够。

## 十三、标准化和平滑后，还有哪些检查？

本节的 `maxResliceNonfiniteFraction` **只用于头动后有限值处理函数**，不是把所有后续输出统一按10%放行。

| 位置/函数                                                                         | 当前检查                                                     | 不能据此声称什么                                       |
| ----------------------------------------------------------------------------- | -------------------------------------------------------- | ---------------------------------------------- |
| [smooth_record.m](../matlab/+psy/smooth_record.m)                             | 平滑前后帧数、TR、维度和affine一致，记录请求/实际选项                          | 不检查全帧信号的每个值，不估计残差有效FWHM，也不判断配准                 |
| [normalise_output_check.m](../matlab/+psy/normalise_output_check.m)，用于群体标准化写出 | 全帧帧数/TR/网格、每帧非有限比例，拒绝Inf或完全无有效非零信号                       | 不应用本节0.1上限；部分NaN可被记录而不拒绝，不能称“全部有限”             |
| [verify_spatial.m](../matlab/+psy/verify_spatial.m)，另行调用                      | 旧逐run SPM组织布局下的全帧值检查、组织概率及部分叠加；启用Smooth隐式掩模时识别记录中的合法缺失位置 | 不是任意CAT/共享结构/DARTEL/Shooting布局的通用审查器，也不是完整人工QC |
| [verify_realign.m](../matlab/+psy/verify_realign.m)，历史辅助函数                    | 抽查首/中/末帧、均值图和运动图                                         | 不是全帧检查；历史帧数/命名假设也不覆盖所有dummy及新路线                |

因此，“文件齐全”“QC完成”“平滑前后网格一致”“每帧有限”和“科研解释可靠”是不同层次。详细的平滑边界见 [SMOOTHING.md](<Spatial Smoothing.md>)，标准化分支见 [NORMALIZATION.md](Normalization.md)。

## 十四、常见异常怎样处理？

| 现象/错误                                 | 常见排查方向                            | 当前程序行为               |
| ------------------------------------- | --------------------------------- | -------------------- |
| FD尖峰或标记较多                             | 运动参数、原图、任务时间、头动与条件是否相关            | 记录，不自动删帧或生成spike回归列  |
| DVARS突然升高                             | 看对应及相邻帧，区分运动、任务、生理和扫描问题           | 记录曲线，不自动套统一阈值        |
| tSNR很高但覆盖很少                           | 是否把低信号脑区都排除了，掩膜是否错误               | 不会仅据高tSNR判合格         |
| `psy:NonfiniteFrame`                  | 是否误把带NaN的原SPM输出直接送进时序QC，或输入确有异常   | 时序QC停止，不静默填值         |
| `psy:FinalizeInf`                     | 输入、上游数值和重采样结果                     | 拒绝把Inf当作正常共同视野NaN    |
| `psy:FinalizePattern`                 | NaN位置是否随帧改变、上游是否失败、当前分支是否适用       | 拒绝固定缺失置零策略           |
| `psy:FinalizeCoverage`                | 缺失过多，或有效信号区不足100体素；核对FOV、方向、运动和掩膜 | 该run失败；不要只调高阈值       |
| Grid mismatch / `psy:FinalizeGrid`    | 同一网格是否混用了配准前后文件、不同run或不同空间        | 拒绝计算，不自动重采样          |
| `psy:QCExists` / `psy:FinalizeExists` | 目标已有成功结果或失败半成品                    | 要求新目录，不覆盖            |
| `QC_COMPLETE.mat`不存在                  | 是否关闭QC、缺均值图、仅预检、只生成VDM或运行失败       | 结合计划、日志及状态表判断，不能只看目录 |

主预处理批次是否在单run失败后继续，由 `cfg.continueOnError` 决定。失败目录可能已经写出部分副本；不要把它当成功结果或让旧完成标记代替本次状态。

多个被试可先逐run查看同一套指标，再按研究设计汇总分布。当前这些检查没有自动生成整组QC评分、组间头动检验或统一的被试剔除决策，也没有根据任务条件检验头动混杂。
