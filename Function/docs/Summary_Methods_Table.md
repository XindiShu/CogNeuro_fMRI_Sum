# fMRI 分析方法表

| 类别             | 方法                                                                                                     |
|:-------------- |:------------------------------------------------------------------------------------------------------:|
| **局部活动与时序特征**  | ALFF、fALFF、ReHo、样本熵、排列熵、直方图熵、自相关时间尺度                                                                   |
| **功能连接**       | Pearson相关、Spearman相关、偏相关、种子到体素连接、加权功能连接、任务背景连接、Beta-series连接、同源配对连接、OAS收缩连接、网络内外连接分析                   |
| **任务调制与有效连接**  | PPI、gPPI、任务DCM、Spectral DCM、DCM模型比较、PEB、BMR、BMA                                                        |
| **数据分解与连接梯度**  | 空间组ICA、双回归、成分间功能连接（FNC）、连接梯度、梯度对齐                                                                      |
| **动态连接与脑状态**   | 滑动窗口功能连接、高斯隐马尔可夫模型（HMM）、共激活模式（CAP）、LEiDA、状态动力学分析                                                       |
| **模式解码与泛化**    | ROI解码、Searchlight解码、线性判别分析（LDA）、Ridge回归、线性SVM、逻辑回归、跨被试泛化、跨任务泛化、跨时段泛化                                   |
| **表征相似性与成分建模** | 相关距离RSA、欧氏距离RSA、Crossnobis RSA、Searchlight RSA、RDM模型比较、固定模型PCM、多成分PCM、PCM交叉验证                          |
| **编码与脑—行为建模**  | Ridge编码、Banded Ridge编码、连续时序滞后编码、连接组预测建模（CPM）、嵌套Ridge预测、PLS协方差分析、PLS回归、CCA、正则化CCA、线性中介分析                |
| **自然刺激与共享表征**  | 被试间相关（ISC）、被试间功能连接（ISFC）、共享反应模型（SRM）、有序事件分段                                                            |
| **图论与网络分析**    | 图论指标分析、社区划分、网络密度敏感性分析、保度零网络分析                                                                          |
| **计算行为模型**     | Rescorla–Wagner学习模型、Softmax选择模型、二选项漂移扩散模型（DDM）                                                         |
| **统计推断与信度**    | 一样本t检验、BH-FDR校正、置换检验、最大统计量校正、网络统计（NBS）、共享相位随机化、Moran空间随机化、Spin检验、被试Bootstrap、RSA噪声天花板、组内相关系数（ICC）、分半信度 |
