# 认知神经 fMRI 插件首次配置

这是插件的首次配置向导。接入已有工具包，不安装或改写其算法，不启动研究分析。用户点击插件的配置入口或明确调用 `$cogneuro-setup` 时执行。

1. 根据本skill实际文件位置找到插件内相邻的 `../cogneuro-fmri/SKILL.md`。读取它以理解三包的现成接口和研究流程；不要要求把插件复制到固定D盘，也不要在插件缓存内存储用户路径、数据或结果。
2. 沿用用户已提供的安装信息，分轮补齐：三个工具包的实际根目录、可运行的Python 3.10+、MATLAB程序文件、按路线需要的SPM根目录、可写工作父目录及环境档保存位置。仅使用部分工具包或暂未选择SPM时可保存部分环境，并说明未核对项。路径候选由文件存在性和包标记核对，不能把作者示例路径当作用户事实。
3. 检查本地执行端确实能看到这些路径。MATLAB提供程序文件；SPM提供含 `spm.m` 的目录。软件候选存在不代表许可、运行库或第三方方法可用。不为环境检查运行MATLAB分析、全套测试或工具包的execute=false分支。
4. 将选择的工作父目录与三个工具包、skill、SPM分开。用户同意创建新工作目录时可以创建；环境档使用用户选定的新文件，例如工作父目录内的 `cogneuro-environment.local.json`。保留已有环境档，更新时另存新名字；不要修改官方配置或插件安装目录。
5. 使用本skill的 `scripts/environment.py create` 保存路径并只读检查原接口。参数如下，按需省略未提供的软件/包路径：

```text
python -X utf8 <本skill>/scripts/environment.py create --workspace-root <已存在工作父目录> --output <新的环境档JSON> --preprocessing-root <预处理包> --glm-root <GLM包> --function-root <分析包> --matlab-executable <MATLAB程序> --spm-root <SPM根目录>
```

该脚本只检查文件、配置源码及现有模板关系，不调用任何原分析入口。缺少包文件或未选择的软件如实报告，不把 `paths_recorded` 称为所有方法已可执行。若返回非零或存在缺项，解释具体问题，继续完成不依赖缺项的配置。

6. 展示实际路径、已记录的包与接口数量、尚未选择的软件、检查范围和环境档链接。后续研究使用 `$cogneuro-fmri`；用户已明确提出研究目标时，直接读取环境档继续已有skill的盘点与问答，遵守研究执行确认规则。只要求安装配置时，完成配置后停止，不自行选择研究方案。

新的对话中需提供环境档路径；不声称Codex已把它存为全局记忆。可给用户以下启动文本，替换为本次真实路径：

```text
请使用 $cogneuro-fmri，先读取环境档 <本次环境档的绝对路径>。
数据目录是 <数据路径>，新项目目录是 <工作父目录内尚不存在的项目目录>。
先核对环境，再询问从哪一步做到哪一步、实验范式和研究目标，方案确认后执行。
```

恢复或复查环境时运行：

```text
python -X utf8 <本skill>/scripts/environment.py check --profile <已有环境档JSON>
```

`check`不改已有文件。若目录、配置源码或接口映射变化，报告差异并重新审阅，必要时另存新环境档。Python路径记录的是实际运行本脚本的解释器，专用GLHMM/PyDDM环境在选定方法时再配置。
